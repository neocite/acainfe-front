---
name: Política pública de versionamento da API
description: Compromisso aprovado pelo proprietário sobre versões e descontinuação da API pública.
---

A API pública usa versão no caminho; mudanças incompatíveis exigem uma nova versão. O proprietário estabeleceu permanência de pelo menos 90 dias para rotas ou versões descontinuadas, com anúncio na página de desenvolvedores e no guia para agentes.

**Why:** Esse prazo e a comunicação foram explicitamente aprovados como política pública do produto, não sugeridos pelo agente.

**How to apply:** Coordenar alterações entre a API e a documentação do site. Os cabeçalhos Deprecation e Sunset pertencem às respostas de operações efetivamente descontinuadas; documentar a política não significa acrescentá-los indiscriminadamente às rotas do site.
